Make sure the following are installed:

* Node.js
* npm
* Angular CLI
* Git

Check your installation:

```bash
node --version
npm --version
ng version
git --version
```

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/PoovarasanMoorthy29/Learn-Angular.git
```

### 2. Navigate to the project

```bash
cd Learn-Angular
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
ng serve
```

Open your browser and visit:

```text
http://localhost:4200
```

## 🧪 Learning Approach

I follow a **learn → build → break → fix → repeat** approach.

For each concept:

```text
📖 Learn the concept
       ↓
💻 Write the code
       ↓
🧪 Experiment
       ↓
🐛 Find & fix errors
       ↓
🔨 Build a small example
       ↓
📝 Document what I learned
```

This helps me understand how Angular works in real applications rather than memorizing syntax.
